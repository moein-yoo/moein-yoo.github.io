# Moein Yousefinia — Personal Website

Source for [moein-yoo.github.io](https://moein-yoo.github.io), a lightweight static portfolio for my work in electrical engineering, analog/RF design, signal processing, and computational neuroscience.

## Stack

- Semantic HTML5
- Responsive CSS
- Small, dependency-free JavaScript interactions
- GitHub Pages deployment from `main`

## Structure

```text
.
├── index.html      # Content, metadata, and interactions
├── styles.css      # Responsive visual system
├── robots.txt
└── sitemap.xml
```

## Local preview

No build step is required. From the repository root:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.
